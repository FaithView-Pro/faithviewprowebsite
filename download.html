Setup

Running in four steps

1

Download

Grab the Windows installer above. It's a standard setup — no account needed to start the trial.

2

Install

Run the installer and follow the prompts. FaithView Pro lands on your desktop in a couple of minutes.

3

First-run model download

On first launch, the app downloads the detection models and Bible translations once. After that, everything runs offline.

4

You're live

Build a service, plug in your projector, and start the detection listener. Sunday just got simpler.

System requirements

  • Windows 10 or 11, 64-bit
  • 8 GB RAM minimum (16 GB recommended)
  • Microphone or audio line-in, for detection
  • ~2 GB free disk space for models & media
  • Second monitor / projector output recommended
  • NDI tools (optional, for streaming output)
